# goport rename table (docs/goport-design.md § 5): <Go qualified name> <Kotlin name>
#
# Only for names the systematic rules map onto an existing Kotlin name in the same scope (the
# porter refuses to write such a collision). Keyed by the GO name, so a rename never makes an
# override stale.

# ast.NodeVisitor has exported VisitX and unexported visitX with identical signatures.
github.com/microsoft/TypeScript/tsc/internal/ast.NodeVisitor.visitNode visitNodeImpl
github.com/microsoft/TypeScript/tsc/internal/ast.NodeVisitor.visitEmbeddedStatement visitEmbeddedStatementImpl
github.com/microsoft/TypeScript/tsc/internal/ast.NodeVisitor.visitNodes visitNodesImpl
github.com/microsoft/TypeScript/tsc/internal/ast.NodeVisitor.visitModifiers visitModifiersImpl

# collections.OrderedMap / OrderedSet: exported Clone (nil-safe) and unexported clone.
github.com/microsoft/TypeScript/tsc/internal/collections.OrderedMap.clone cloneImpl

# binder: exported BindSourceFile (bound-check wrapper) and unexported bindSourceFile (the worker).
github.com/microsoft/TypeScript/tsc/internal/binder.bindSourceFile bindSourceFileImpl

# A method of a named MAP/SLICE type is an extension on a GoMap/GoSlice typealias; one named like a member of
# that runtime class is SHADOWED by it ((TSGO.5): `m.Get(name)` resolved to GoMap.get and lost the lower-case
# fallback, so --showConfig printed no compilerOptions). The porter refuses the build until it is renamed.
github.com/microsoft/TypeScript/tsc/internal/tsoptions.CommandLineOptionNameMap.Get getOption

# One object per node (docs/goport-lowering.md § 3): ast.SourceFile EXTENDS ast.Node there, whose `data` field
# (the node's nodeData) it would shadow; Go keeps them apart as a promoted field and a shallower one.
github.com/microsoft/TypeScript/tsc/internal/ast.SourceFile.data sourceFileData

# (TSGO.7.1) TypeScript 7.1's `compiler.declarationTransformer` interface makes DeclarationTransformer forward the
# PROMOTED `Transformer.TransformSourceFile` (*SourceFile result); its own unexported `transformSourceFile` (*Node
# result) lowers to the same Kotlin name.
github.com/microsoft/TypeScript/tsc/internal/transformers/declarations.DeclarationTransformer.transformSourceFile transformSourceFileImpl

# (TSGO.7.1) project.Project has both `ID() ID` and `Id() string` (ls.Project requires the latter as `id`).
github.com/microsoft/TypeScript/tsc/internal/project.Project.ID projectID
# (TSGO.7.1) project.aliasPaths is a named map: its `Len()` would be GoMap's own `len`.
github.com/microsoft/TypeScript/tsc/internal/project.aliasPaths.Len aliasCount
