# Contributing

Thank you for your interest in xemantic-typescript-compiler.

## Pull requests

**External pull requests cannot be merged at this time.** The project is licensed
`AGPL-3.0-only WITH LicenseRef-xtsc-output-exception`, and until a contributor
agreement is in place we cannot accept code contributions from outside the project.
This file will change the moment that agreement exists.

## What is very welcome today

- **Issues** — wrong diagnostics, crashes, hangs, wrong emitted JavaScript,
  performance surprises, divergences from `tsc`.
- **Reproductions** — the most useful thing you can send: a minimal `.ts` file
  (or a small project with its `tsconfig.json`), the command you ran, the output
  you expected, and the output you got.

Please file both at
<https://github.com/xemantic/xemantic-typescript-compiler/issues>.
